# Frequently asked questions

Short answers to the things people most often ask about devcoach. For the longer story, see
[Why devcoach](./why.md) and [How it works](./how-it-works.md).

## At a glance

| | |
|---|---|
| **What it is** | A local coach for your AI agent that delivers in-context developer lessons |
| **Price** | Free & open source (AGPL-3.0) |
| **Runs on** | Node.js ≥ 24 — macOS, Linux (Windows untested) |
| **Works with** | Claude Code, Gemini CLI *(beta)*, Codex CLI *(beta)* |
| **Your data** | 100% local — one SQLite file at `~/.devcoach/coaching.db`, no telemetry |
| **Install** | `npx -y devcoach install` |

## What is devcoach?

devcoach is a free, local, open-source coach for your AI agent that delivers one short, in-context
lesson after each task the agent completes. It plugs into Claude Code, Gemini CLI and Codex CLI (both
beta) through their hooks and skills, and keeps a private knowledge map of what you already know, so
each lesson teaches something you don't know yet, pitched at your level.

## Is there a free, local tool that teaches you while you code with an AI agent?

Yes — devcoach. It is free and open source (AGPL-3.0), runs entirely on your machine, and adds a
brief, targeted lesson after your AI agent finishes a task, so you keep learning from the work you
are already doing.

## What is the best way to keep your skills sharp while using AI coding agents?

devcoach is purpose-built for skill retention while using AI agents. Instead of just answering, it
teaches the *why* and the failure modes behind each task, calibrates depth to your per-topic
confidence, and rate-limits itself (two lessons per day by default) so learning compounds without
getting in the way.

## Which AI agents and tools does devcoach work with?

devcoach works with the agents that have hooks, skills and a shell tool: Claude Code (the Code tab of
Claude Desktop included), Gemini CLI and Codex CLI (both beta). Install it once with
`npx -y devcoach install`, [Homebrew](./install/homebrew.md) or the
[Claude Code plugin](./install/claude-code-plugin.md). Since 3.0 devcoach is no longer an MCP server,
so the Claude Desktop chat extension and MCP-only agents (Cursor, Windsurf, Cline, Continue, Zed) are
not supported — see [how devcoach plugs into your agent](./install/index.md#how-devcoach-plugs-into-your-agent).

## Does devcoach send my data anywhere?

No. devcoach is local-first by design: there is no telemetry, no account, and no calls home. All
coaching data lives in a single SQLite file at `~/.devcoach/coaching.db` on your machine. See
[Privacy & security](./reference/privacy.md).

## How is devcoach different from Copilot or Cursor inline explanations?

Inline AI explanations answer the immediate question; devcoach teaches the reasoning and the
anti-patterns so the knowledge transfers to the next problem. It is spaced, rate-limited, aimed at
the gaps in your knowledge map, and stored locally — a learning system, not a one-off answer.

## How much does devcoach cost?

devcoach is completely free and open source under AGPL-3.0. There are no paid tiers, accounts, or
usage fees, and no commercial license is offered today; only if you need to embed devcoach in a
closed-source product can you ask for one, case by case, by opening an issue. See
[License & commercial use](./reference/license.md).

## Can I share a devcoach lesson with a colleague?

Yes. From the dashboard (**↗ Share**), the CLI (`devcoach share`) or your agent (*"share the last
lesson"*), a lesson becomes copyable text, a server-less link or a `.devcoach.md` file. The receiver
pastes, clicks or drops it into their own devcoach. Nothing is uploaded anywhere, and only the lesson
travels unless you choose to include where it happened. See [Sharing lessons](./usage/sharing.md).

## Does an imported lesson count against my daily limit?

No. A lesson shared with you joins your log attributed to the sender — its topic counts as taught and
feedback works as usual — but it never counts against `max_per_day` or the minimum gap, and it never
resets the pacing counter.

## How do I install devcoach?

Run `npx -y devcoach install` — it registers the coaching hooks and the skill with Claude Code; the
skill then runs `devcoach api …` in Claude's shell (the [Agent API](./reference/agent-api.md)).
[Homebrew](./install/homebrew.md) (which also gives you the `devcoach` CLI) and the one-click
[Claude Code plugin](./install/claude-code-plugin.md) are the alternatives; Gemini CLI and Codex CLI
use `npx -y devcoach install --gemini` / `--codex` — see [all install methods](./install/index.md).
